# 말로만들DOT 시작 화면

아두이노 만들기 서비스의 시작 화면 초안입니다. 영상 재생 후 버튼이 나타나고, 버튼을 누르면 로고의 점이 반짝입니다.

## 실행하기

별도의 설치 없이 `index.html`을 브라우저에서 열면 됩니다. 또는 이 폴더에서 아래 명령을 실행한 뒤 브라우저에서 `http://localhost:8000`에 접속하세요.

```bash
python -m http.server 8000
```

영상은 소리 없이 한 번 재생됩니다. 자동 재생이 차단되거나 움직임 줄이기 설정을 사용 중이어도 버튼을 볼 수 있습니다.

## 현재 범위

- `index.html`: 화면 구성
- `styles.css`: 화면 스타일
- `app.js`: 영상과 버튼 애니메이션
- `intro.mp4`, `poster.jpg`: 시작 화면 영상과 대체 이미지

버튼은 아직 다른 화면으로 이동하거나 백엔드에 연결되지 않습니다. 현재는 클릭 애니메이션만 동작합니다.

## 팀 프로젝트에 합치기

나중에 팀 저장소의 새 브랜치에서 이 화면을 React 컴포넌트로 옮기고, 영상 파일을 프로젝트의 정적 파일 폴더에 추가하세요. 버튼에는 팀에서 만드는 다음 화면으로 이동하는 동작을 연결할 수 있습니다. 이 저장소만으로 백엔드나 아두이노가 연결되지는 않습니다.
