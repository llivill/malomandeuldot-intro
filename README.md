# 말로만들DOT 성인용 화면 초안

말로만들DOT 시작 화면과 초보자를 위한 만들기 흐름을 볼 수 있는 프런트엔드 시연입니다.

## 실행하기

`index.html`을 브라우저에서 열거나 이 폴더에서 아래 명령을 실행한 뒤 `http://localhost:8000`을 열어주세요.

```bash
python -m http.server 8000
```

## 화면 흐름

시작 화면 → 홈 → 보드 선택 → 보드 준비 → 아이디어 입력 → 동작 구체화 → 요청 확인

보드 선택과 입력은 화면에서 체험할 수 있으며, 뒤로 돌아가 내용을 바꿀 수 있습니다. 홈의 모니터링은 준비 중 안내만 표시합니다. 기기 정보 입력은 시연용이며 실제 기기에 전송하거나 저장하지 않습니다.

실제 보드 연결, 요청 분석, 설계, 부품 추천, 배선, 프로그램 생성 및 모니터링은 아직 구현되지 않았습니다.

## 구성

- `index.html`: 화면 구조
- `styles.css`, `adult-home.css`, `adult-flow.css`, `adult-review.css`: 화면 스타일
- `app.js`: 시작 화면 애니메이션과 화면 전환
- `intro.mp4`, `poster.jpg`, `sora-latin-600.woff2`: 시작 화면 영상, 대체 이미지와 폰트
